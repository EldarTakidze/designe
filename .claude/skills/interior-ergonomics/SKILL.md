# Эргономика жилья: нормы и проверка

Проект: квартира 117 м² для семьи из 7 человек (2 взрослых, бабушка, подросток 17 лет,
трое мальчиков 7, 6 и 3 лет). Источник геометрии: `tools/source_walls.json`.

## Как проверять

1. Правим `tools/design.py`.
2. `python3 tools/design.py` — печатает площади помещений и замечания эргономики
   (`tight` = по минимуму, `bad` = нарушение).
3. `python3 tools/render_check.py A out.png` — PNG плана для визуальной проверки.
4. `python3 tools/build_page.py` — собрать страницу.

Нарушений `bad` в сданном варианте быть не должно. Каждое `tight` нужно назвать
заказчику с вариантом, как его снять.

## Зоны подхода (минимум / комфорт, мм)

Правила лежат в `tools/ergonomics.py`, таблица `RULES`. Мерим по центральным 40% фасада.

| Предмет | Минимум | Комфорт | Примечание |
|---|---|---|---|
| Распашной шкаф | 700 | 900 | шкаф-купе: 600 / 750 |
| Открытая система хранения, гардеробная | 700 | 800 | двусторонняя гардеробная: проход ≥ 700 |
| Комод | 700 | 900 | выдвинуть ящик и присесть |
| Рабочий стол | 750 | 900 | стул и выход из-за стола |
| Кровать: подход сбоку | 600 | 700 | двуспальная — обе стороны; односпальная у стены — одна |
| Кровать: в ногах | 600 | 800 | только для двуспальной |
| Кухонный фронт, холодильник, духовка | 1000 | 1200 | между рядами 1000–1200 |
| Унитаз: перед ним | 600 | 750 | от оси до стены сбоку ≥ 400 |
| Раковина | 700 | 800 | |
| Ванна: выход | 700 | 800 | |
| Стиральная/сушильная машина | 800 | 900 | загрузка и выгрузка |
| Распашная дверь | дуга свободна | | иначе — купе или пенал |

## Проходы и движение

- Основной коридор ≥ 900 (здесь 1100–1150), второстепенный проход ≥ 700.
- За стулом у обеденного стола: ≥ 750 до стены, ≥ 900 если за ним ходят.
- Обеденный стол: 600 мм на человека по длине.
- Рабочий треугольник кухни: мойка — плита — холодильник, сумма сторон 4–7 м, мойка между плитой и холодильником.

## Детская (дети 3–7 лет)

- Верхний ярус — с 6 лет, бортик ≥ 300 мм над матрасом, под потолком ≥ 900 мм над матрасом.
- Стол: 800–1000 мм по длине на ребёнка, свет слева для правши.
- Крючки и нижние полки на высоте 1000–1200 мм: дети одеваются сами.

## Пожилой человек

- Подход к кровати ≥ 900 с одной стороны, высота сиденья кровати 500–550.
- У ванны и унитаза поручни, тёплый пол без порогов.

## Семья из 7 человек: что проверять сценариями

- Утро: сколько человек на каждый санузел (норма — не больше 3).
- Стирка: путь от машин до глажки и до шкафов с бельём.
- Гости: путь от входа до кухни-гостиной не проходит через спальни.
- Ночь: путь спальня → туалет без выхода в общий коридор, ночная подсветка.
